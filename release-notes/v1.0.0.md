**NetPulse 1.0.0** for Windows 10/11 (x64) · Free for personal use

### What's new

- Initial public release
- Exact per-app traffic from Windows kernel network events
- Packets: live capture on every adapter, decoding, plain-English explanations and a hex view
- Packet timeline slider, sortable columns and a click-to-filter breakdown chart
- Firewall: per-app and timed blocks, block new apps, block all internet
- Security checks, connection quality with outage causes, and your home network's devices
- Data usage for any range, kept up to a size you choose
- World map, alerts, tools (ping, traceroute, DNS lookup, public IP) and a Help page
